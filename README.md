# Aura Life OS — Unified Personal Life Management & Productivity System

A high-performance, **Local-First Personal Life Operating System** designed to unify task management, schedule optimization, habit building, focus analytics, journaling, and intelligent life coaching into a single dashboard.

Engineered with a client-side architecture, **Aura Life OS** runs 100% inside modern web browsers using IndexedDB and LocalStorage, offering zero server latency, complete data privacy, and seamless offline capability.

---

## 🌟 Key Features

*   ⚡ **Local-First Architecture:** All data is saved natively inside your browser. Zero cloud tracking, zero server dependencies.
*   📊 **Unified Dashboard:** Real-time daily productivity score calculator, quick focus actions, and active habit matrix.
*   🎯 **Task & Goal Management:** Subtask decomposition, priority tagging, category filtering, and progress tracking.
*   🔥 **Habit Heatmap Matrix:** Annual activity logs, streaks, completion rates, and custom reminders.
*   ⏱️ **Focus Stopwatch & Analytics:** Category-based deep work logging, duration metrics, and SVG charts.
*   📖 **Daily Reflections & Mood Tracking:** Morning intentions, evening reviews, mood/energy correlation analytics.
*   🤖 **Intelligent Life Coach:** Automated weekly heuristic analysis delivering wins, warnings, and schedule optimizations.
*   🔐 **Data Ownership & Backup:** One-click JSON backup export and import.

---

## 🚀 Tech Stack

*   **Frontend Framework:** React 18 + Vite
*   **Icons & Styling:** Lucide React, Glassmorphism CSS Design Tokens
*   **Storage Engine:** Client-side IndexedDB & LocalStorage Engine
*   **Deployment:** Compatible with Netlify, Vercel, and GitHub Pages Static Edge CDNs

---

## 💻 Local Development

```bash
# Clone repository
git clone https://github.com/nagarjun012/Personal-Tracker.git

# Install dependencies
npm install

# Start Vite Development Server
npm run dev

# Build Static Bundle for Production
npm run build
```

---

## 🌐 Netlify One-Click Deployment

1.  Import repository into [Netlify](https://app.netlify.com/).
2.  Set Build Command: `npm run build`
3.  Set Publish Directory: `dist`
4.  Deploy!
